04 / On-Premise & Security

          
「数据不出内网」
这句话写进架构里。

        

        
对制造、医疗、政企来说，能不能上 AI，往往不是效果问题，是数据能不能出这个门。所以我们只做本地。

      


      

        

          
01 — DATA

          
数据不出域

          
推理、向量检索、文件解析全部在内网完成。模型权重、知识库、日志都落在你指定的机器上，不经过任何第三方服务。

        

        

          
02 — OFFLINE

          
断网可运行

          
镜像、模型、依赖一次性离线交付。产线断网、机房隔离、涉密环境，功能不打折，不会因为外网抖动停摆。

        

        

          
03 — AUDIT

          
全链路可审计

          
谁问的、检索了哪些文档、调用了哪个技能、返回什么，逐条留痕。配合 RBAC 与部门级数据隔离，越权即拒绝。

        

      


      

        

          
三种交付形态

          按你的机房条件选，不强行上云
        

        

          

            

              
              GPU 一体机
            

            
整机交付，开箱接内网。适合没有专职运维团队、又要求数据绝对隔离的场景。

            
单机 1–4 卡 · 开箱即用 · 本地运维面板

          

          

            

              
              私有云 / K8s
            

            
部署进企业已有的容器平台，按部门分配算力与命名空间，和现有系统共用一套账号体系。

            
多租户 · 弹性扩缩 · 对接 LDAP / SSO

          

          

            

              
              边缘 / 工控机
            

            
车间、门店、机房现场就地推理，只把结果回传中心。带宽占用低，断网仍可独立工作。

            
CPU / 轻量 GPU · 低功耗 · 离线授权
